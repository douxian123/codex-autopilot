# Codex 自动挡 · 入门

## 一句话
你平时打字的那个 **Codex 输入框，就是总输入框**。视觉不对、体验别扭、冒出一个 bug——
原样说出来就行，不用新建对话、不用挑分支、不用派给哪个角色。归类、记录、追踪、收口由自动挡自己做。

## 它替你做了什么
- 把零散的反馈收进唯一入口，归类到固定泳道，写进项目台账。
- 把和主线无冲突、构建门禁通过的分支**自己合进 main**。
- 遇到冲突分支，不丢给你逐条裁决，而是自动拆成可执行任务逐条收口。
- 只在三种情况停下来问你：改产品方向、删数据、发布。

## 第一次怎么用（三步）
1. 重启 Codex 桌面端 / CLI，在 Plugins → Personal 里确认「Codex 自动挡」已安装。
2. 回到任意项目的对话，直接说话。例如：
   > 左边导航排版坏了，顺便这个按钮点着没反应，另外首页有点慢。
3. 需要看状态 / 开关时，说一句“打开自动挡面板”，或调用 `render_autopilot_panel`，
   面板里有：怎么用、现在在做什么、为什么、替你完成了什么、随时暂停。

## 面板在哪
- 对话里说“打开自动挡面板” -> inline 卡片。
- 侧栏：全局侧栏或对话侧栏的「Codex 自动挡」入口（点开是全屏/侧栏体验）。
- 面板第一屏就是给不熟的人看的：怎么用 + 当前状态 + 暂停按钮；点「高级」才展开开关与队列。

## 常用操作（用户可以直接说，也可以让面板做）
- “暂停自动挡” / “恢复自动挡” -> 暂停后不再启动新工作，当前 Git 操作安全收尾。
- “现在检查一轮” -> 立刻跑一个周期（暂停中会拒绝，不会偷偷跑）。
- 高级里可开关：自动合入安全改动、自动拆解冲突、自动移植小改动、后台常驻。

## 边界
- 它不改 Codex 本体、不换输入框、不要求你改工作习惯。
- 它不替你做产品判断，也不删数据、不发布。
- 归类是启发式的，可能判错泳道；判错只影响优先级，不致命。
